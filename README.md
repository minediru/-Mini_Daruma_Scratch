# ミニだるまスクラッチ (Mini Daruma Scratch)

昔ながらの縁日・お祭りの屋台をイメージした、レトロで賑やかな4マスのスクラッチくじゲームです。
指（スマートフォン）やマウスドラッグ（PC）でスクラッチカードを削り、隠れている「だるま」を集めて等級を競います。

---

## 🎯 ゲームのルール

1. **4つのスクラッチマス（2×2）**を画面上に配置しています。
2. それぞれのマスを削ると、**「だるま」**または**「スカ（何もなし）」**が現れます。
3. 各マスは**45%以上削られると自動的に完全に開き**、結果が確定します。
4. **4つすべてを開くまでは最終結果は表示されません。**
5. 4つすべて削り終わると、出現しただるまの総数に応じた等級が表示されます。

### 当せん等級表と出現確率（標準：等倍設定）

| 等級 | 条件 | 確率 |
| :--- | :--- | :--- |
| **🥇 1等** | だるま **4体** | **25%** |
| **🥈 2等** | だるま **3体** | **25%** |
| **🥉 3等** | だるま **2体** | **25%** |
| **😭 ハズレ** | だるま **1体** | **25%** |

※ ルール上、**だるま0体（0個）は厳禁**となっており、必ず最低1体のだるまが出現します。  
※ 抽選されただるまの配置場所は毎回ランダム（例：だるま2体の場合は4マス中2マスがランダムに選ばれます）です。

## ⚙️ 屋台の裏設定機能（画面右下）

画面右下の「**⚙️ 屋台設定**」ボタンから、以下の設定を自由に変更・保存できます（ブラウザのLocalStorageに保存されます）：

1. **1等の文言カスタマイズ**
   - 1等の等級タイトル（例: `🥇 1等！` を `✨ 特賞 旅行券！` などに変更可能）
   - 1等のお祝いメッセージ
   - 2等・3等・ハズレのタイトルもカスタマイズ可能
2. **当せん確率の調整**
   - 各等級の確率（0%〜100%）をスライダーまたは数値で自由に調整可能
   - ワンタッププリセット：
     - `⚖️ 等倍にする（各25%）`
     - `🏮 通常確率（50:30:15:5）`
     - `✨ 1等確定（100%）`
3. **設定の即時反映**
   - 設定を保存すると画面上の「当せん等級早見表」にも新しい文言・確率が自動反映され、新しいくじですぐに遊べます。

## 💻 ローカルでの動作確認方法

特別なビルド手順なしで、ブラウザですぐに動作確認できます。

### 方法1: VS Code の Live Server を利用する場合
1. VS Code で本フォルダを開きます。
2. 拡張機能「Live Server」をインストールします。
3. `index.html` を右クリックして「Open with Live Server」を選択します。

### 方法2: Python の簡易サーバーを利用する場合
```bash
python -m http.server 3000
```
ブラウザで `http://localhost:3000` を開きます。

## 🌐 Vercelへのデプロイ方法

本アプリは外部依存やサーバー処理のない純粋な静的ファイルで構成されているため、Vercelにそのままワンクリックでデプロイできます。

1. [Vercel](https://vercel.com/) にログインし、「**Add New...**」→「**Project**」をクリックします。
2. GitHubリポジトリを選択（Import）します。
3. **Framework Preset** は「**Other**」またはデフォルトのままで「**Deploy**」ボタンを押します。
